# Phase plans

[PLANS.md](../../PLANS.md) owns sequence and authorisation; [GOALS.md](../../GOALS.md)
owns outcomes; [the project log](../build-log.md) owns execution status.

Each phase includes sources, objective/scope/non-goals, dependencies and owners,
authorisation, meaningful RED/GREEN/refactor or justified document/visual checks,
verification commands (or clearly unresolved discovery work), operational/recovery
considerations, acceptance and evidence/handoff. Use the [workflow](../../PROMPTS.md).
No empty future contexts or evidence receipts. No application-specific Proof rules.
